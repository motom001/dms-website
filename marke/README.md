# Ablago – Logo und Farben

*[English](README.en.md)*

Hier liegen alle Fassungen des Ablago-Logos. Alle anderen Repositories (Ablago selbst, Handbuch, Paketkatalog, App-Stores, Clients) beziehen Logo und Farben **von hier**, damit es überall gleich aussieht.

## Farben

| Name | Wert | Wofür |
|---|---|---|
| Blau | `#1F4E79` | Hauptfarbe, Kachel des App-Symbols |
| Akzent | `#E8A33D` | das Blatt im Logo, sparsam für Hervorhebungen |
| Dunkel | `#141A22` | dunkle Hintergründe |
| Blau im Dunkelmodus | `#2A6496` | nur für das App-Symbol auf dunklen Flächen, nicht im Logo selbst |
| Text hell | `#E6ECF3` | Schrift auf dunklen Hintergründen |

## Dateien

| Datei | Wofür |
|---|---|
| `ablago-app-blau.svg` | App-Symbol, Standard (blaue Kachel) |
| `ablago-app-dunkelmodus.svg` | App-Symbol für dunkle Umgebungen (helleres Blau) |
| `ablago-app-hell.svg` | weiße Kachel mit Rand, für helle Flächen |
| `ablago-zeichen-farbig.svg` | Zeichen ohne Kachel (blau/orange), z. B. im Kopf einer Oberfläche |
| `ablago-zeichen-einfarbig.svg` | Zeichen in `currentColor`, mit etwas mehr Abstand zwischen Blatt und Fach |
| `ablago-homey-icon.svg` | Homey: einfarbig, durchsichtiger Hintergrund (Homey färbt selbst) |
| `ablago-logo-mit-schriftzug.svg` | Zeichen und Schriftzug „Ablago“ für helle Hintergründe |
| `ablago-logo-mit-schriftzug-dunkel.svg` | dasselbe für dunkle Hintergründe |
| `favicon.svg`, `favicon.ico` | Browser-Tab (ico mit 16, 32 und 48 px) |
| `png/` | Rastergrößen 16–1024 px; 180 px = Apple Touch Icon, 192/512 px = Web-App-Manifest |

**Schriftzug:** Er ist mit der Schrift *Source Sans 3* (Stärke 600) gesetzt. Wo diese Schrift fehlt, ersetzt der Browser sie. Für Druck und feste Bilder den Text vorher in Pfade umwandeln.

## Regeln

- Der Name heißt **Ablago**: ein Wort, nur das A groß.
- Logo nicht verzerren, nicht umfärben (außer der einfarbigen Fassung) und nicht mit anderen Zeichen kombinieren.
- Rund um das Logo etwas Luft lassen, mindestens ein Achtel seiner Breite.
- App-Symbol nicht kleiner als 16 px, Logo mit Schriftzug nicht schmaler als 120 px.
- Bilder brauchen einen Alternativtext, in der Regel „Ablago“.
