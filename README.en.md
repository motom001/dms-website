# Ablago – website

*[Deutsch](README.md)*

Source of the website of **Ablago**, the document archive for homes and small businesses. It is published with GitHub Pages.

- Ablago itself: [motom001/dms](https://github.com/motom001/dms)
- Package catalog: [motom001/dms-registry](https://github.com/motom001/dms-registry)

## Principles

- **Plain static HTML**, no build step and no dependencies.
- **No cookies, no tracking, no analytics.** The page loads nothing from third parties: images live in this repository, fonts come from the visitor's device.
- **GitHub Pages**, as the host, processes technically necessary data such as the IP address. The page says so openly.
- **Accessible** and **light/dark** following the device setting.

## Status

First draft, German only for now. An English version (`/en/`), pages per audience, imprint and privacy notice, and packages loaded live from the catalog will follow.
